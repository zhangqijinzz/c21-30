# LatencyLab

本地前端请求链路预算实验室。这里的推演是可重复的时间估算，不会调用真实接口。

## 本地运行

- 运行时：Node.js `>=20 <21`
- 安装依赖：`npm ci`
- 开发预览：`npm run dev`
- 质量门：`npm run lint`、`npm run test`、`npm run typecheck`、`npm run build`

## 功能模块

1. 链路项目：新建、改名、切换与复制项目。
2. 请求编排：增删节点、设置依赖及耗时、超时、重试、失败和降级参数；依赖变成环时拒绝连线。
3. 时序推演：乐观、预期、保守三种波动假设；不限并发或设置并发上限；展示完成预算、排队等待和关键链路。
4. 方案对比：保存当前图和计算结果，比较两份参数快照并恢复任一快照。
5. 本地项目区：管理、复制和删除项目，查看保存状态。

## 架构

`views` 只渲染状态并转发事件。功能 VM 将项目、节点、推演和方案用例分开编排；纯规则位于 `shared/domain`；Repository 依赖 IndexedDB Service，并写入版本化 localStorage 恢复副本。项目数据不会发到服务器。

默认示例：会话校验和功能开关并发启动；资料与目录在会话后开始；个性推荐等待功能开关和资料。结果使用确定性预算：延迟波动取所选情境、超时截断单次耗时、失败概率决定重试次数期望，重试退避按 200ms 指数增长并封顶 2 秒。

### 降级路径的预算口径（v2）

- **主路径与降级路径分行呈现**：主路径条表示请求必然发生的投入（截断耗时 × 重试概率 + 退避）；降级路径以虚线条单独成行，只在主路径全部尝试最终失败时触发。
- **按失败概率折算**：降级行同时展示原始耗时与折算耗时（`原始耗时 × 触发概率`，触发概率 = `失败率^(重试次数+1)`），避免把只在失败链路上发生的请求误读为每次必执行而高估预算。
- **降级目标还有下游请求时**：下游分支只在“目标也最终失败”后才继续，触发概率沿链条件概率连乘（如 `P(主失败) × P(目标失败)`）；降级链回到链上节点成环时，在成环处截断并给出警告。
- **完成预算**仍为各节点「主路径 + 折算后降级」的期望占用，并发上限按稳定拓扑顺序做资源排队估算。
- **旧方案兼容**：已保存快照锁定其保存时口径的完成时间（无 `budgetVersion` 标记的按 v1），不会被重算覆盖；方案对比页对 v1 快照按 v2 重算一份并标注差额是否纯粹来自口径调整，差额来源可对照。
